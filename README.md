# olimtime.com

Shop page for @olimtime: vintage dress watches currently for sale.

- `index.html` — the whole page (styles included)
- `img/` — watch photos, 1000px wide JPEGs

Hosted on Cloudflare Pages, deployed automatically from the `main` branch.
No build step: Cloudflare serves the files as they are.

To update a listing: edit the watch's `<article>` block in `index.html`,
replace or add the photo in `img/`, commit and push.
